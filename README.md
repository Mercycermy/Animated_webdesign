# Animated Web Design Collection

This repository is a collection of the best 3D and animated websites available on GitHub. It is curated for developers and designers who are looking for inspiration or high-quality learning resources in modern web design.

The collection focuses on immersive 3D experiences, advanced motion graphics, and interactive user interfaces built with cutting-edge technologies.

## Contribution

Contributions are welcome! If you know of a high-quality 3D or animated website repository that should be included, please follow these steps:

### How to Submit
1. Fork the repository.
2. Add the project to the appropriate category section.
3. Ensure the project meets the quality rules below.
4. Submit a pull request.

### Submission Rules
- The project must have a working live demo or a clear video preview.
- Animation or 3D effects must be a core feature of the project.
- The project must be open-source on GitHub.
- Code should be clean and well-structured.

### Submission Format
Project Name
Repo: <link>
Demo: <link>
Description: Short explanation of what makes this project interesting
Tech: List of main technologies
Stars: Star count
