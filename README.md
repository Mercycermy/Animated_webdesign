# 3D and Animated Web Design Collection

This repository is a curated collection of some of the best 3D and animated websites available on GitHub. It features immersive experiences, advanced motion design, and interactive UI experiments built with modern web technologies. This resource is made for developers and designers looking for inspiration or learning resources to elevate their frontend skills.

## Contribution

Contributions are welcome. If you know a high-quality project that should be part of this collection, please feel free to submit it.

### How to submit a new project

1. Fork the repository
2. Add the project to the relevant category in the README.md file
3. Follow the existing format and quality rules
4. Submit a pull request

### Basic quality rules

- The project must have a working demo or a preview
- The animation or 3D effect must be a core feature of the site
- The code should be clean and well-structured
- Avoid submitting duplicate or very similar projects

### Example submission format

### Project Name
- Repo: [link]
- Demo: [link]
- Description: Simple explanation of why this project is interesting
- Tech: List of main technologies
- Stars: Number
